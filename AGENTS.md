# For agents

This folder is the `unsupervised` skill. It installs, sets up and runs
Architech, Mutagent's software-engineering harness, from any agent harness that
can read files and run shell commands.

If you were asked to install, set up or run Architech, or to hand it a task,
read [SKILL.md](SKILL.md) and follow it. It has three phases (start, setup,
operate), starts with what your harness needs, and lists ground rules you must
keep: ask the user before you install or write anything, and never merge for
them. Paths in SKILL.md are relative to this folder.

If you are here for any other reason, ignore this file.
